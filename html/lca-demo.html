二叉树最近公共祖先：单次 DFS 演示

题目对应截图中的 LeetCode 236。任意二叉树不具备二叉搜索树的有序性质，因此最稳的做法是一次后序 DFS： 左子树找一次、右子树找一次，如果两边都找到了目标，当前节点就是最近公共祖先。

时间复杂度 O(n)
额外空间 O(h)
节点最多访问 1 次

时间复杂度优先的核心代码

// 题目保证 p、q 都在树中。每个节点最多进入一次。
function lowestCommonAncestor(root, p, q) {
  if (root === null || root === p || root === q) {
    return root;
  }

  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);

  if (left !== null && right !== null) {
    return root;
  }

  return left !== null ? left : right;
}

为什么是 O(n)： 这个算法不反复从根节点查路径，不为每个节点二次搜索。 DFS 对每个节点只处理常数次，所以最坏情况下访问 n 个节点，时间复杂度为 O(n)。
