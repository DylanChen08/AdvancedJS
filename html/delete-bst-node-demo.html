450. 删除二叉搜索树中的节点

删除 BST 节点时，先利用大小关系只沿一条路径查找 key；找到后分三种情况处理：叶子节点、只有一个子树、有两个子树。两个子树时，用右子树最小节点作为后继替换当前节点。

平均时间复杂度 O(h) ≈ O(log n)
最坏时间复杂度 O(n)
核心原因 每层只进入左子树或右子树，不需要遍历整棵树

层序结果 [5,3,6,2,4,null,7]

理解重点

1. 没有子节点：直接删除，返回 null。
2. 只有一个子树：让父节点直接接上这个子树。
3. 有两个子树：找右子树最小值替换，再删除后继节点。
function deleteNode(root, key) {
  if (!root) return null;

  if (key < root.val) {
    root.left = deleteNode(root.left, key);
  } else if (key > root.val) {
    root.right = deleteNode(root.right, key);
  } else {
    // root 就是要删除的节点
    if (!root.left) return root.right;
    if (!root.right) return root.left;

    let next = root.right;
    while (next.left) next = next.left;
    root.val = next.val;
    root.right = deleteNode(root.right, next.val);
  }

  return root;
}
