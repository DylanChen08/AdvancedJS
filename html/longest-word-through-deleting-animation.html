524. 通过删除字母匹配到字典里最长单词

枚举字典中的每个单词，用双指针判断它是否是字符串 s 的子序列。能匹配时，再用长度和字典序维护当前最优答案。

测试用例

  • 1. 对每个 dictionary[i] 执行一次子序列匹配。
  • 2. 如果 s[i] === word[j]，说明匹配到一个字符，j++。
  • 3. 扫描结束后，j === word.length 才表示整个单词匹配成功。
  • 4. 成功单词更长，或长度相同但字典序更小，就更新答案。
function isSubsequence(s, word) {
  let j = 0;
  for (let i = 0; i < s.length; i++) {
    if (s[i] === word[j]) j++;
  }
  return j === word.length; // 匹配完成
}
