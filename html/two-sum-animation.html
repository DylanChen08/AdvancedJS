两数之和：双指针演示

这里演示排序数组里的两数之和。left 从最小值开始，right 从最大值开始。当前和小于 target，就让 left 右移变大；当前和大于 target，就让 right 左移变小。

核心代码

let left = 0;
let right = nums.length - 1;

while (left < right) {
  const sum = nums[left] + nums[right];

  if (sum === target) return [left, right];
  if (sum < target) left++;
  else right--;
}
