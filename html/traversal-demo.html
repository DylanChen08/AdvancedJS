二叉树遍历：先序、中序、后序

三种 DFS 遍历的区别只有一个核心点：什么时候访问“根节点”。 左子树和右子树的递归方向不变，变化的是根节点在递归过程中的位置。

先序 Preorder 根 → 左 → 右
中序 Inorder 左 → 根 → 右
后序 Postorder 左 → 右 → 根

怎么记

先、中、后 指的是“根节点”的访问时机。 左右子树总是按“先处理左，再处理右”的方向递归。
先序先访问根，再进入左子树和右子树。
中序左子树处理完，回到根，再处理右子树。
后序左右子树都处理完，最后访问根。

递归模板

// root 是当前子树的根节点
function traverse(root) {
  if (root === null) return;

  // 先序：在这里访问 root
  traverse(root.left);
  // 中序：在这里访问 root
  traverse(root.right);
  // 后序：在这里访问 root
}
