双指针算法动态演示

场景：在一个有序数组中找两个数，使它们的和等于目标值。左指针从小数开始，右指针从大数开始，每次根据当前和决定移动哪一边。

当前目标值 target
13
left
right
1 + 10 = 11
当前和等于目标值，找到答案。

控制

左指针：当前较小的数
右指针：当前较大的数
绿色：找到答案

步骤记录

核心代码

while (left < right) {
  const sum = arr[left] + arr[right];

  if (sum === target) return [left, right];
  if (sum < target) left++;
  else right--;
}
