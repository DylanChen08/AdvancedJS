16. 最接近的三数之和

先把数组排序。每轮固定一个数 i，然后在它右侧用 left 和 right 两个指针夹逼。当前三数和偏小就移动 left，偏大就移动 right，同时记录离 target 最近的 sum。

控制

指针含义

i：固定第一个数
left：从 i 右边开始找较小数
right：从数组末尾开始找较大数
bestSum：当前最接近 target 的和

步骤记录

核心代码

nums.sort((a, b) => a - b);
let best = nums[0] + nums[1] + nums[2];

for (let i = 0; i < nums.length - 2; i++) {
  let left = i + 1;
  let right = nums.length - 1;

  while (left < right) {
    const sum = nums[i] + nums[left] + nums[right];
    if (Math.abs(sum - target) < Math.abs(best - target)) {
      best = sum;
    }
    if (sum < target) left++;
    else if (sum > target) right--;
    else return sum;
  }
}
